# SYNTHOMA Cyklus Cards Patch v6

Šestý průchod nad kartami. Navazuje na v5.

## Rozsah

Upravené karty: **101 až 130**

Od:

- `bookmark_knows_more`

Po:

- `token_collector`

## Co se změnilo

- Přidáno `sceneHtml` a `sceneFx` pro dalších **30 karet**.
- Celkem má nyní soubor **130 karet se scénovým HTML**.
- Posíleny následky dřívějších rozhodnutí: špatná jména, odmítnutí, portálové platby, návrat kontroly integrity, vynucené update chování, úroky bolesti, paměťové reklamace a tržiště žetonu.
- Přidány CSS akcenty pro:
  - hranice / odmítnutí,
  - portálové mýtné,
  - falešně čisté místnosti,
  - diagnostiku,
  - integritu,
  - overheat,
  - memory leak,
  - bolest a dluh.
- Opraveny drobné překlepy:
  - `ODMÍTNOU ZNOVA` → `ODMÍTNOUT ZNOVA`
  - `nepodpisany` → `nepodepsaný`
  - `tvoje podpis` → `tvůj podpis`
  - `Anebysis` → `A nebyl jsi`

## Poznámka

Mechanika karet zůstala nedotčená. Změny jsou narativní, vizuální a drobně textově korekční. Engine tedy nemá důvod se teatrálně složit na zem, i když by to tematicky sedělo.
