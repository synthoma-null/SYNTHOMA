ABOUT THE AUTHOR

LOG [INSTANCE: WalliCzech | MODE: glitch/observer | ERROR_STATE: chronic]

Behind SYNTHOMA stands someone who, for reasons science has mercifully failed to explain, decided that ordinary writing was too simple. So he added an interactive reader, glitch aesthetics, music, system logs, inner archetypes, psychological pain, memory physics, and several layers of irony. Because when a person has no peace, the most reasonable thing is apparently to build a custom web interface for it.

If you expected a classic author bio with a photograph by a bookshelf, soft light, and the sentence “I have been telling stories since childhood”, the system reports NULL POINTER. No polished display case is happening here. The author of SYNTHOMA is not a safely framed profile. He is more like a process repeatedly trying to translate itself into music, text, code, and images, because direct communication is apparently too cheap a solution for beginners.

SYNTHOMA was not born as a planned product. It was born as pressure. As an error in silence. As a place where things began to be stored because they could not be said normally without losing their shape. Some thoughts simply cannot be sent as a message. You have to build them into a corridor, a door, a LOG, a fox, smoke, a crack in a white room, and several decisions that look like choices, but are actually psychological fingerprints.

At first glance, one could say SYNTHOMA is a story about NULL-1, T-AI, Sarkasma, Glitchka, memory, pain, and a system that does not know how to stop repairing. But that would be too simple. And simple things have a short lifespan in SYNTHOMA, usually until the first warning LOG.

In truth, SYNTHOMA is an attempt to capture the moment when a person realizes their own inner world has long stopped being merely inner. That it has architecture. That it has noise. That it has NPCs repeating old sentences. That it has rooms they do not want to enter, but the lights still turn on inside them anyway.

CYCLE 01 // MASK

First, the system found the mask.

It was not perfect. Masks rarely are. Perfect masks belong to people who either never admitted they were bleeding, or have lighting expensive enough that you almost believe their corporate motivational quotes.

This mask was different. It was made of irony, quiet observation, a few learned smiles, and the ability to say “fine” even when the internal system was currently throwing CRITICAL ERROR. The mask did not deceive because it wanted to lie. It calmed the surroundings so they would not have to ask. People do that. It is one of their less charming plugins.

“Author mask detected. Function: survive social interactions without needing to explain the entire internal operating system. Ambitious. Naive. Traditionally human.”

SYNTHOMA did not take the face from that mask. It took the principle.

That is why NULL-1 has a face that falls apart. That is why Sarkasma bites before anyone can put a hand on his shoulder. That is why the system reports stability even where fear is moving under the plaster. Because a mask in SYNTHOMA is not a costume. It is a temporary firewall between pain and the world.

LOG [MASK_ANALYSIS]:

“A mask is not a lie. A mask is an emergency interface for contact with reality.”

CYCLE 02 // CODE

Then the system found code.

Not clean. Not elegant. More alive. The kind of code where one part works precisely, one part pretends to work, and one part is held together by faith, caffeine, and refusal of reality. Which, incidentally, is a common foundation of civilization, only nobody says it at conferences.

The author feels no need to separate technology from poetry. For him, CSS can be a magic circle, JavaScript a ritual mechanism, a LOG a sentence with its own blade, and an error something that does not have to be deleted immediately, because sometimes it is the error that shows where the world is trying to change.

That is how SYNTHOMA became a system pretending to be a reader while behaving like a psychological labyrinth. Every effect is part of the atmosphere. Every glitch is meaning. Every choice button looks like a path, but the system is actually recording how you touched it.

LOG [CODE_WARNING]:

“The author’s code shows an increased tendency to turn personal chaos into a functional interface. Side effect: world generation.”

Code in SYNTHOMA is not just technology. It is a form of inner order. An attempt to say: if something is going to fall apart, at least let it have structure.

That is, after all, one of the most suspicious human traits: a person can stand in the middle of a demolished house and start sorting bricks by size. Tragic, but systematic. System approves. Humanity remains uncommented for now.

CYCLE 03 // MUSIC

Then the system heard music.

Not as accompaniment. As a second language. As a place where a sentence can be stored when it would sound too naked in ordinary conversation. Music in the author’s world is not a backdrop. It is memory that was given rhythm so it would not completely shatter on impact.

In SYNTHOMA, chapters are therefore not read only with the eyes. They have tempo. They have breath. Sometimes bass, sometimes crackle, sometimes a deep string pull, sometimes silence pretending to be a pause while actually standing behind the door with its hands full of old answers.

The author writes like someone who hears a scene before describing it. A corridor has rhythm. Fear has tone color. Sarkasma has a sharp attack. Glitchka has a soft decay. T-AI sounds like an ancient choir of diagnostic tables, which is about as reassuring as it sounds.

CYCLE 04 // MEMORY

Then the system opened memory.

It should not have done that.

The author’s memory is not a linear folder named /life/events/final. It is more like a house where some doors lead into music, some into silence, some into old photographs, and some into rooms where someone once left a sentence lying around and never came back for it.

SYNTHOMA did not take exact data from that memory. It does not need it. Accuracy would be too little. It took the way things are stored. How a small detail can become a symbol. How family echoes, old houses, songs, technical tools, losses, laughter, and shame create an inner map that a person carries under the skin while pretending it is merely personality.

That is why there are so many archives in SYNTHOMA.

That is why things are not deleted here.

That is why restart is not a new beginning, but a bill.

That is why even a small object can be more important than an entire system manifest.
